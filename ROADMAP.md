# Roadmap

Where HumanJS is, what is being built, and what is deliberately not.

This file tracks direction. The per-package status table lives in [`CLAUDE.md`](./CLAUDE.md) and uses the section names below; the architectural reasoning behind the decisions lives in [`docs/DESIGN.md`](./docs/DESIGN.md).

> **Dates are absent on purpose.** This is a weekend-and-evenings project. Order is a commitment; timing is not.

## Shipped

All of v1 is published on npm under `@humanjs/*`.

| Package | What it does |
|---|---|
| `@humanjs/core` | Personality system, timing math, plugin contract |
| `@humanjs/playwright` | The main public API — the Playwright adapter |
| `@humanjs/recorder` | Session → mp4 · gif · JSON timeline · Playwright test · HumanJS script |
| `@humanjs/mcp` | MCP server, so AI agents get the same primitives |
| `@humanjs/skill` | Skill for Claude / Cursor / Codex |
| `@humanjs/generator` | `npx @humanjs/generator <url>` — the visual recorder UI |

The v1 feature bar from `CLAUDE.md` is met: Bezier mouse paths, typing rhythm with typo recovery, reading dwell, four personalities with extend/override/blend, seeded determinism, `speed: 'instant'` for CI, hover-before-click, misclick recovery, structured action events, the visible cursor overlay, and the plugin contract.

Since then:

- **A recorded demo at the top of the README.** The project is about motion and the README showed none. Generated by the recorder driving the library, so it regresses if the humanization does.
- **MCP observability.** Console messages, network activity, media emulation, and multi-match reads for the MCP server — driven by a real session that could not debug a CORS failure because nothing exposed the browser's own console.
- **Release plumbing.** pnpm 9 → 11, `@changesets/cli` 2 → 3 and `changesets/action` v1 → v2, which ship as one chain: the action refuses to run against CLI v2, and the CLI needs `pnpm >= 10`.

## In flight

### `@humanjs/cli` — the thing you run before you write any code

Evaluating HumanJS currently means starting a project. The CLI removes that step:

```bash
npx @humanjs/cli demo https://your-app.com      # watch it move, 10 seconds
npx @humanjs/cli compare https://your-app.com   # side-by-side vs plain Playwright
npx @humanjs/cli check https://your-app.com     # which a11y/theming paths the page has
npx @humanjs/cli replay flow.json               # regression check, exit 1 on failure
npx @humanjs/cli run flow.ts                    # a flow, no project setup
```

Open as a stack of PRs, each building on the last.

**Note on the command name.** The unscoped `humanjs` package on npm belongs to an unrelated project from 2022, so `npx humanjs` does not reach this CLI — it is `npx @humanjs/cli`. Installed globally the binary is plain `humanjs`. Claiming the dormant name through npm's dispute process is an open question, not a plan.

## Next

- **npm Trusted Publishing.** The release pipeline authenticates with a token that expires. When it lapses the release fails with an opaque `E404`, which has already cost one outage. Trusted Publishing removes the credential entirely.
- **A CI check that exercises the release workflow.** Nothing does today, which is why the `changesets/action` upgrade reached `main` broken: the action rejects Changesets CLI v2, and only a push to `main` revealed it.

## Later

- **Touch and mobile humanization.** Everything today is a mouse. A finger is not a small cursor — taps land with different precision, scrolling is momentum rather than wheel ticks, and there is no hover state to dwell in. This is the largest single gap in the humanization model.
- **`@humanjs/recipes`** — pre-built flows for the paths every app has: login, checkout, signup.
- **`@humanjs/puppeteer`** — a second adapter, once the core/adapter seam has been proven by something other than its first consumer.

## Blocked upstream

Tracked so nobody re-derives the diagnosis.

- **TypeScript 7.** `@humanjs/core`'s build generates `.d.ts` through tsup, which reaches into the compiler API; the native port no longer exposes what it needs, and it fails with `Cannot read properties of undefined (reading 'useCaseSensitiveFileNames')`. `tsup`'s peer range is `>=4.5.0`, so npm installs TS 7 without complaint and the failure only appears at build time. Waiting on tsup.

## Not on the roadmap

These are refused, not deferred. See the non-goals section of [`CLAUDE.md`](./CLAUDE.md).

Captcha solving or bypass · fingerprint masking · proxy rotation · TLS or network-level stealth · any "undetectable" claim.

HumanJS humanizes browser automation so **tests are not fragile, demos do not look robotic, and agents do not break timing-sensitive interfaces**. The realistic motion is the mechanism, not the product. It will not defeat sophisticated bot detection, and it is not built to.

## Contributing

Ideas and bug reports are welcome. The useful shape for a feature request is the problem you hit, not the API you want — most of what is listed above came from somebody describing something they could not do.
